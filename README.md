# DSCI 552 - Homework 7

SVM classification and k-means clustering on the Anuran Calls dataset, plus ISLR Exercise 12.6.2.

- [Notebook](Oliver_Austin_HW7.ipynb)
- [Extra practice notebook](Oliver_Austin_HW7_Extra_Practice.ipynb)
- [Assignment](Homework7.pdf)

The data are in `data/`. Tested with Python 3.11. Install the packages with `pip install -r requirements.txt`, then open the notebook in Jupyter or VS Code and run all cells from this folder. The random seed is 552.

The extra practice covers classifier chains, additional classification metrics, and the remaining ISLR 12.6 exercises. It runs independently using the included data.
